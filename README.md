# ProBalance – Biuro Rachunkowe

Strona www biura rachunkowego ProBalance. Statyczny HTML/CSS/JS, publikowana przez GitHub Pages.

- `assets/news.js` – aktualności podatkowe i kadrowe (nowy wpis dopisz na początku tablicy `NEWS`).
- `assets/main.js` – kalkulator podatkowy (tablica `TAX`), menu, formularz.
- Formularz kontaktowy wysyła zapytania przez FormSubmit na adres z `#contact-email` w `index.html`. Po pierwszym wysłaniu FormSubmit prosi o aktywację e-mailem (kliknij „Activate”).
- Po podpięciu własnej domeny: zamień `https://probalance.pl/` w `index.html`, `sitemap.xml` i `robots.txt` na właściwy adres i dodaj plik `CNAME`.
