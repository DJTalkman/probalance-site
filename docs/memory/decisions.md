# Рішення

Нові записи додавай зверху. Не переписуй старі: якщо рішення змінилося, додай новий запис і познач старий як «замінено».

Формат запису:

```
## РРРР-ММ-ДД — Коротка назва
Рішення: що вирішили.
Чому: причина, обмеження, що відкинули.
```

## 2026-11-14 — Пам'ять проєкту зберігається в репозиторії
Рішення: стан і рішення ведемо у `docs/memory/`, оновлюємо командою «підсумуй сесію».
Чому: працює і в хмарних, і в локальних сесіях, не передає дані стороннім сервісам.
