# Стан проєкту

Оновлено: 2026-11-14

## Що це

Односторінковий сайт бухгалтерського бюро ProBalance з податковим калькулятором, новинами й формою контакту.

## Зроблено останнім (за git log)

- Калькулятор: повзунок, що відповідає підписам шкали, і ручне введення суми.
- Canonical і og:url ведуть на адресу GitHub Pages.
- Тексти: бухгалтерія для всіх бізнесів, консолідація як окрема послуга.

## В роботі

- Не зафіксовано.

## Далі

- Підключити власний домен: замінити адресу в `index.html`, `sitemap.xml`, `robots.txt` і додати `CNAME` (кроки в `README.md`).

## Пам'ятай

- Сайт публікується через GitHub Pages, тож злиття в `main`, імовірно, одразу потрапляє на сайт (джерело публікації не перевірено).
